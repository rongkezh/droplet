# Droplet game

This is a droplet game.

size of the default cheseboard: 10X10.

each grid can have 0 to 9 droplets. 

When a grid receive a droplet, it would check its size. When a grid of size 9 gets an additional water splash, it would pop and splashes to four directions: up, down, left, right.

The player starts with 10 splashes of water. When it goes down to 0, game is over.
